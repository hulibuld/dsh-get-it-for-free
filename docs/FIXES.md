## 以后怎么加一行

修完一次就加一行，别攒着——攒三个月再回忆，原因那一列就只能写「未记录」了。

1. 修复版本：改了 `package.json` 的 version 就算一个新行。
2. 修复日期：提交日期。
3. 现象：用户看到的是什么，不写技术描述。
4. 原因：能说清才写，说不清写「未记录」。
5. 修复方式：一句话说清动了什么。
6. 提交：短 SHA。
